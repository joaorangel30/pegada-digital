# Pegada Digital

Uma ferramenta web simples que ajuda o usuário a entender e refletir sobre o impacto (ambiental e de privacidade) das suas atividades online, como uso de IA, streaming e redes sociais, incentivando hábitos mais conscientes de consumo digital.

🔗 **Acesse o site:** [joaorangel30.github.io/pegada-digital](https://joaorangel30.github.io/pegada-digital/)

## Como Instalar

1. Clone este repositório para a sua máquina:
```bash
   git clone https://github.com/joaorangel30/pegada-digital.git
```
2. Entre na pasta do projeto:
```bash
   cd pegada-digital
```
3. Abra o arquivo `index.html` diretamente no seu navegador (basta dar duplo clique nele ou usar a extensão "Live Server" do VS Code).

Não é necessário instalar dependências adicionais, pois o projeto é feito com HTML, CSS e JavaScript puros.

## Como Usar

Você pode acessar a versão online direto pelo link acima, ou rodar localmente. Exemplo de uso:

1. Abra o index.html no navegador (ou acesse o link do GitHub Pages)
2. Preencha as informações solicitadas (ex: horas de uso de internet por dia)
3. Clique em "Calcular" ou "Ver resultado"
4. Veja o resultado da sua pegada digital na tela
